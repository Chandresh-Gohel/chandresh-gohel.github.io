Graph-Native Agent Memory - HydraDB

Agent memory as a timestamped knowledge graph in HydraDB: Cypher traversal over SUPERSEDES edges, with no embeddings or vector store. A structural abstention gate deterministically refuses when the subgraph is empty, so it gives no fabricated answers, and it outperformed a long-context baseline on a LongMemEval subset.

End-to-End vs. Hybrid Pipelines: Quantifying Performance Trade-offs in Sonar Object Detection for Autonomous Underwater Vehicles

C. Gohel and S. Dhavale

Where does hybrid sonar preprocessing earn its keep? The paper benchmarks 12 YOLO configurations on the Caltech Fish Counting dataset, comparing end-to-end detectors against hybrid pipelines built on MOG2 + TVG tensors, pseudo-labels and a Kalman-centroid filter, with edge deployment timings on Jetson Orin.
